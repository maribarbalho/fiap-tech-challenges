# Tech Challenges · Pós-graduação em Data Analytics (FIAP)

Projetos desenvolvidos nos Tech Challenges da pós-graduação em Data Analytics da FIAP. Cada fase propõe um problema de negócio, da análise exploratória ao modelo de machine learning.

| Fase | Projeto | Principais técnicas |
|---|---|---|
| [Fase 1](fase-1-vitivinicultura) | Exportação, consumo e produção de vinho | Pandas, análise exploratória, visualização |
| [Fase 2](fase-2-previsao-ibovespa) | Previsão do fechamento do Ibovespa | Séries temporais, AutoARIMA, XGBoost, LSTM |
| [Fase 3](fase-3-pnad-covid) | Comportamento da população na pandemia (PNAD COVID-19) | Consultas SQL, Pandas, Plotly |
| [Fase 4](fase-4-obesidade-ml) | Modelo preditivo de obesidade | Pipeline scikit-learn, Random Forest, XGBoost |
| [Datathon](https://github.com/maribarbalho/datathon) | Estruturação das bases de candidatos, vagas e prospecções | Pandas, JSON |
